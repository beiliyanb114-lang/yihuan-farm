异环 店长特供 1-1 自动刷 —— 照着做

第一次用
--------------------------------------------
1. 装 Python 3（python.org 下载），装的时候记得勾上 Add Python to PATH
2. 打开这个文件夹，在地址栏敲 cmd 回车，然后执行：
       pip install -r requirements.txt
   （就是 numpy、pillow、pywin32 三个包）

标定（必须做一次）
--------------------------------------------
双击 1-标定.bat。

它会先把浏览器收起来、游戏顶到前面，截一张图弹出来。在图上按住左键拖个框，
框住提示里说的东西：

   1  主城里店长特供的入口（已经停在店长特供界面里了就右键跳过）
   2  1-1 新品练习那张卡
   3  右下角开始营业
   4  店里左边发光的 100T 锤子
   5  店里左上角的返回箭头
   6  结算界面的领取

框错了按 Backspace 撤销，右键跳过，R 重新截图，S 保存。

开刷
--------------------------------------------
双击 3-开始刷.bat。

先问你要刷几轮：直接回车 = 一直刷，输个数字比如 20 就跑 20 轮。
然后会弹 UAC，点允许。浏览器自动收起来，游戏跳到前面，数 5 秒开跑。

F12 随时停，F10 暂停，F9 继续。
跑完或者被停会弹个窗口告诉你刷了几轮，点确定关掉就行。

换了分辨率或者窗口模式？
--------------------------------------------
重新跑一遍 1-标定.bat，别的不用管。

点了游戏没反应？
--------------------------------------------
权限问题。跑一下 0-体检.bat，它会把权限、截屏、坐标都列出来。
多半就是没给管理员。

一轮要多久、花多少活力
--------------------------------------------
一轮三十秒上下。开始营业花 2~6 点都市活力，领取再花 18 点。
