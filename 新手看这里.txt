异环 店长特供 1-1 自动刷（娜娜莉 + 白藏）—— 照着做

注意：这脚本是给「娜娜莉 + 白藏」两个角色的技能、在关卡「1-1」上用的。
只有带这两位的组合才能靠技能把人砸走过关，砸 3 个客人营业额就到 100。
换成别的角色，过关方式就变成做菜上菜了，这脚本帮不上忙。

文件夹里就两个 bat：标定.bat 和 开始刷.bat

第一次用
--------------------------------------------
1. 装 Python 3（python.org 下载），装的时候记得勾上 Add Python to PATH
2. 打开这个文件夹，在地址栏敲 cmd 回车，然后执行：
       pip install -r requirements.txt
   （就是 numpy、pillow、pywin32 三个包）

标定（必须做一次）
--------------------------------------------
双击 标定.bat。它会把游戏画面截下来弹出来，你在图上拖框标位置。

这几个位置分在三个界面上，一张图装不下，所以要换界面再按 R 重新截：
   1  店长特供菜单上：1-1 新品练习那张卡、右下角开始营业
   2  进店之后按 R 再截：左边发光的 100T 锤子、左上角返回箭头
   3  点返回让结算界面出来，按 R 再截：右边的领取
   最后按 S 保存

框错了 Backspace 撤销，右键跳过，R 重新截图，S 保存。
标完会生成 config.json 和 tpl 文件夹，别删。

开刷
--------------------------------------------
双击 开始刷.bat。

先问你要刷几轮：直接回车 = 一直刷，输个数字比如 20 就跑 20 轮。
然后会弹 UAC，点允许。浏览器自动收起来，游戏跳到前面，数 5 秒开跑。

F12 随时停，F10 暂停，F9 继续。
跑完或者被停会弹个窗口告诉你刷了几轮，点确定关掉就行。

换了分辨率或者窗口模式？
--------------------------------------------
重新跑一遍 标定.bat，别的不用管。

点了游戏没反应？
--------------------------------------------
权限问题。在文件夹地址栏敲 cmd 回车，跑：
       python doctor.py
它会把权限、截屏、坐标都列出来。多半就是没给管理员。

锤了半天营业额不涨？
--------------------------------------------
先看辅助雇员是不是娜娜莉 + 白藏、关卡是不是 1-1。
都对了还不涨，那就是锤子坐标偏了，重新标定。

一轮要多久、花多少活力
--------------------------------------------
一轮三十秒上下。开始营业花 2~6 点都市活力，领取再花 18 点。
