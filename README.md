# 异环 店长特供 1-1 自动刷（娜娜莉 + 白藏）

自己用的一个小东西。异环每周要刷店长特供攒都市活力，手点太累，一轮三十来秒，几十轮下来手指受不了，就写了这个。

原理很土：截屏看屏幕，SendInput 发鼠标键盘。不读游戏内存、不注入、不改游戏文件。

## 先说清楚：这是给特定角色和关卡的

**这个脚本是给「娜娜莉 + 白藏」两个角色的技能、在关卡「1-1」上用的。**

只有带这两位，才能靠技能直接把客人砸走过关。辅助雇员换成别的组合就没这回事了——那种情况下的过关方式是做菜上菜，这个脚本只会点锤子图标，不会做菜，帮不上忙。

带娜娜莉 + 白藏的情况下，砸中 3 个客人营业额就够 100。

关卡必须是 **1-1 新品练习**。脚本每轮开头会点一次列表里 1-1 那张卡，点成别的关卡坐标全不对。

## 一轮都干了什么

1. 店长特供菜单上点「开始营业」
2. 进店后反复点左边那个发光的 100T 锤子图标，客人被锤飞，营业额往上涨
3. 娜娜莉和白藏的技能加持下，砸中 3 个客人营业额就够 100
4. 点左上角返回，结算界面弹出来，点「领取」，扣 18 点都市活力
5. 回到菜单，1-1 还是选中的，接着来

判断"这一下砸中没有"不是靠数次数，是每锤一下对比营业额那串数字变没变。变了才算砸中，没变就等客人上门再锤。所以不会出现锤了半天其实全砸在空气上的情况。

## 为什么非得用管理员

这条不是凑字数。《异环》自己是以管理员权限跑的。脚本如果是普通权限，发出的鼠标点击会被 Windows 的 UIPI 直接丢掉——而且是静默丢掉，SendInput 照样返回成功。表现出来就是脚本跑得挺欢，游戏里纹丝不动，能让人怀疑人生。

脚本会自己调 ShellExecuteW 提权，UAC 允许一下就行。提权之后的控制台输出在 `logs\console.log` 里。

## 环境

- Windows 10 / 11
- Python 3.8 以上
- `pip install -r requirements.txt`（就 numpy、pillow、pywin32 三个）
- 游戏开窗口化或者无边框全屏。独占全屏是截不到画面的，截出来全黑
- 游戏停在店长特供界面，辅助雇员带娜娜莉和白藏

## 第一次用：先标定

坐标跟着分辨率走，所以第一次必须先标一遍。以后换了分辨率、换了窗口模式，也得重来。

双击 `1-标定.bat`。它会自己把浏览器收起来、游戏顶到前面，截一张图弹出来，让你在上面框六个位置：

- 主城里「店长特供」的入口（已经在店长特供界面里了就右键跳过）
- 关卡列表里「1-1 新品练习!」那张卡
- 右下角「开始营业」
- 店里左边发光的那个 100T 锤子
- 店里左上角的返回箭头
- 结算界面右边的「领取」

框的时候按住左键拖个矩形，松手就算数，框中心就是以后点击的位置。框错了按 Backspace 撤销，右键跳过，R 重新截图，S 保存。

框完会在旁边生成 `config.json` 和 `tpl/`。

## 开刷

双击 `3-开始刷.bat`。

先问你要刷多少轮——直接回车就是一直刷到按 F12，输个数字比如 20 就跑 20 轮。然后自动提权、收起浏览器、游戏置顶，倒计时 5 秒开干。

中途 `F9` 继续、`F10` 暂停、`F12` 停。跑完或者被停会弹个窗口告诉你刷了几轮，别让它一直挂着不知道完没完。

跑完浏览器会自动还原。

## 参数

都在 `config.json` 里，标定完自动生成，也可以手改：

```jsonc
"round": {
  "serve": {
    "point": "hammer",   // 反复点的那个点
    "target_hits": 3,    // 砸中几个客人算满。1-1 + 娜娜莉/白藏 是 3 个
    "max_tries": 18,     // 最多锤几下，砸空了的会重试
    "interval": 0.9      // 锤完等一下再看营业额，给动画留点时间
  },
  "start_sequence": [选 1-1, 开始营业],
  "end_sequence":   [返回箭头, 截个图, 领取],
  "serve_seconds": 120   // 兜底，一轮最多待两分钟
}
```

流程就是普通 JSON，想加步骤直接写：`{"click": "begin", "wait": 2.0}`、`{"wait": 1.5}`、`{"key": "f"}`、`{"shot": "名字"}`。

`money.stable_seconds` 是老版本的兜底判断（营业额多久不动算收满），现在走锤子模式基本用不上了，留着没删。

## 出问题了

点了没反应，八成是权限。跑一下 `0-体检.bat`，它会把权限、截屏活性、坐标越界都列出来。

锤了半天营业额不涨，多半是锤子那个坐标偏了，重新标定。要是坐标没问题还不涨，先检查辅助雇员是不是娜娜莉 + 白藏、关卡是不是 1-1。

截出来全黑，游戏换成无边框窗口。

闪退或者报错，看 `logs\crash_*.log` 和 `logs\console.log`，里面有完整堆栈。

## 文件都干嘛的

`common.py` 干脏活：截屏、SendInput、提权、找窗口、模板匹配。`farm.py` 是主循环。`calibrate.py` 是标定界面。`doctor.py` 是体检。`explore.py` 是我调试用的，可以按指令做动作加截图，比如 `python explore.py "s 截图名 | c 100 200 | w 1"`。
