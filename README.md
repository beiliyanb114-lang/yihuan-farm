# 异环 店长特供 1-1 自动刷（娜娜莉 + 白藏）

用于自动化《异环》「店长特供」中 1-1「新品练习」关卡的通关流程，减少重复操作。

实现方式是屏幕截图识别加 SendInput 模拟鼠标键盘，不读写游戏内存、不注入进程、不修改游戏文件。

## 适用范围

**本脚本面向「娜娜莉 + 白藏」两名辅助雇员，以及关卡 1-1。**

这两名角色的技能可以让客人被锤子砸走直接结算营业额，因此流程简化为重复点击锤子。辅助雇员换成其他组合时，过关方式是制作并上菜，本脚本不涉及该流程，无法使用。

在该配置下，砸中 3 名客人即可达到 100 点营业额。

关卡限定为 1-1。该关卡营业额门槛为 100 点，因此 3 名客人刚好足够；其他关卡门槛更高，同样的操作无法达标。脚本每轮开始时会点击一次列表中的 1-1 卡片，因此无需手动切换。

## 单轮流程

1. 在店长特供菜单点击「开始营业」
2. 进入店内后，重复点击左侧发光的 100T 锤子图标，客人被击退，营业额增加
3. 在娜娜莉与白藏的技能加成下，砸中 3 名客人即达到 100 点
4. 点击左上角返回，在结算界面点击「领取」，消耗 18 点都市活力
5. 返回菜单，1-1 仍处于选中状态，进入下一轮

单轮约 30 秒。

判断一次点击是否命中，不依据点击次数，而是每次点击后对比营业额数字是否发生变化。发生变化的计为一次命中，未变化则等待下一位客人。因此不会出现点击多次却全部落空的情况。

实际空击比例较高。最近一次实测为点击 9 次命中 3 次（第 1、5、9 次各命中一次），因此 `max_tries` 设为 18 以留出余量。

## 为什么需要管理员权限

《异环》以管理员权限运行。脚本若为普通权限，发出的鼠标点击会被 Windows 的 UIPI 拦截并丢弃，且 SendInput 仍返回成功，表现为脚本运行正常但游戏无任何响应。

脚本会自动调用 ShellExecuteW 提权，在 UAC 提示中允许即可。提权后的控制台输出记录在 `logs\console.log`。

## 运行环境

- Windows 10 / 11
- Python 3.8 及以上
- 安装依赖：`pip install -r requirements.txt`（numpy、pillow、pywin32）
- 游戏以窗口化或无边框窗口运行。独占全屏下无法截取画面
- 游戏停留在店长特供界面，辅助雇员为娜娜莉与白藏

## 两个入口

| 文件 | 用途 |
|---|---|
| `标定.bat` | 首次使用时运行，标注界面上的若干位置 |
| `开始刷.bat` | 日常运行入口 |

其余为命令行工具，使用时在文件夹地址栏输入 `cmd` 回车，再执行：

```
python doctor.py                              运行前检查：权限、截屏、坐标
python farm.py --dry-run --auto --rounds 1    空跑一轮，仅打印点击位置，不操作鼠标
```

## 首次使用：标定

坐标与分辨率相关，首次使用必须标注一次。更换分辨率或窗口模式后需重新标注。

双击 `标定.bat`，程序会截取当前游戏画面并显示，在图上拖框标出各位置。

需要注意，这些位置分布在三个不同界面上，单张截图无法全部包含，因此中途需要切回游戏切换界面，再回来按 `R` 重新截图。

**第一张：店长特供菜单**

停留在可点击「开始营业」的界面开始标注，标注两处：

- 关卡列表中的「1-1 新品练习!」卡片
- 右下角的「开始营业」

主城入口一项右键跳过即可，脚本默认使用者已停留在菜单。

**第二张：店内**

切回游戏，点击「开始营业」进入店内，待店内画面出现后切回标定窗口，按 `R` 重新截图。标注两处：

- 左侧发光的 100T 锤子图标
- 左上角的返回箭头

进入店内会消耗少量都市活力，标注完成后返回并退出即可。

**第三张：结算界面**

回到游戏点击左上角返回，待结算界面出现后切回标定窗口，按 `R` 重新截图，标注右侧的「领取」，最后按 `S` 保存。

拖框方式为按住左键拖动，松开即记录，框的中心为后续点击位置。框选错误按 Backspace 撤销，右键跳过。

标注完成后会在同目录生成 `config.json` 与 `tpl/`，请勿删除。

## 开始运行

双击 `开始刷.bat`。

程序会先询问运行轮数：直接回车为持续运行直至按 F12，输入数字（例如 20）则运行指定轮数。随后自动提权、收起浏览器窗口、将游戏置前，倒计时 5 秒后开始。

运行中 `F9` 继续、`F10` 暂停、`F12` 停止。结束后会弹窗提示完成的轮数。

运行结束后浏览器窗口会自动恢复。

## 配置说明

配置位于 `config.json`，标定后自动生成，也可手动修改：

```jsonc
"round": {
  "serve": {
    "point": "hammer",   // 重复点击的位置
    "target_hits": 3,    // 命中次数目标。1-1 配合娜娜莉、白藏为 3 次
    "max_tries": 18,     // 最大尝试次数，未命中会重试
    "interval": 0.9      // 每次点击后等待时间
  },
  "start_sequence": [选 1-1, 开始营业],
  "end_sequence":   [返回箭头, 截图, 领取],
  "serve_seconds": 120   // 单轮时限，超出则结束
}
```

流程以普通 JSON 描述，可自行增删步骤：`{"click": "begin", "wait": 2.0}`、`{"wait": 1.5}`、`{"key": "f"}`、`{"shot": "名称"}`。

## 常见问题

点击后游戏无响应，通常为权限问题。运行 `python doctor.py`，可查看权限、截屏状态与坐标范围。

点击多次营业额不增加，一般为锤子坐标偏移，需重新标定。若坐标无误仍不增加，请确认辅助雇员为娜娜莉与白藏、关卡为 1-1。

截图全黑，请将游戏改为无边框窗口。

程序异常退出时，查看 `logs\crash_*.log` 与 `logs\console.log`，其中包含完整堆栈。

## 文件说明

`标定.bat` 与 `开始刷.bat` 为两个入口。`common.py` 提供底层能力：截图、SendInput、提权、窗口查找、模板匹配。`farm.py` 为主循环。`calibrate.py` 为标定界面。`doctor.py` 为运行前检查。`explore.py` 用于调试，可按指令执行动作并截图，例如 `python explore.py "s 截图名 | c 100 200 | w 1"`。
